# 2014 年 12 月 N1 试排内容

由用户提供的 `N1 12-2014.pdf`（13 页）经本地日文 OCR、页面对照和题目结构整理得到。
文字卷包含 70 题；听力包含 15 道印刷选择题以及原稿的无印刷题目说明，不含音频和答案。
这是供版式评估和进一步校对的整理稿，不等同于官方电子题库。

## 编辑与构建

- `V.yaml`：词汇问题 1–4。
- `G.yaml`：语法问题 5–7，含排序例题和完形材料。
- `R.yaml`：阅读问题 8–13，含问题 11 的 A/B 文本框和问题 13 的两张文字表格。
- `L.yaml`：听力问题 1–5。

安装项目依赖并确保 `xelatex` 在 `PATH` 中，然后在项目根目录执行：

```sh
python build.py --paper paper-2014-12 --booklet written --blueprint blueprints/2014-12-written.yaml
python build.py --paper paper-2014-12 --booklet listening --blueprint blueprints/2014-12-listening.yaml
```

这套题含有内置子集未覆盖的字符。构建前请按 `docs/FONTS.md` 在根目录 `fonts.yaml` 配置 Ryumin 和 FutoGo B101 完整字体；字体无需安装到系统，也不会提交到 Git。

## 排版与校对范围

采用项目的 A4 模板重新排版，增加模板封面及背纹，页数不与原始 13 页合订整理版相同。
问题 11 的 A/B 框按内容分别计算高度，问题另起页。
问题 13 采用左页问题、右页日程表，因此说明中的“下のページ”调整为“右のページ”；日程表为可编辑文字，不是截图。
题号、选项、下划线及主要 OCR 错字已对照页面整理；全角/半角和题型说明按模板统一。
正式用作试卷前仍需逐题校对原稿；PDF 构建校验验证的是 YAML 到 PDF 的一致性，不能证明 OCR 本身没有错误。
