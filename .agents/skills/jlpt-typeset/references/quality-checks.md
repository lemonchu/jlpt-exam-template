# PDF 验收与常见问题修复

每次生成后执行适用项目。完整新卷逐页看；修复既有卷至少看全部变化页及邻页，分页变化须追踪到后续单元和卷尾。无法查看图像时，将视觉检查标为未完成，不能用文字抽取或测试通过代替。

## 先确定检查的对象

- 本次编译进程成功，`build-report.json` 为 `compiled: true`；实际 PDF 的页数与报告一致。输出目录不能与基准混用。
- 记录文件名、构建参数、修改范围；批量交付核对每份最终 PDF 的摘要，防止目录中仍混入旧版。
- `examples/` 是已确认的生成样例，官方原稿是另一个参考；二者不能混称。来源扫描含歪斜/污点时，不把扫描缺陷机械复制到新卷。

## 必查项目

### 内容与卷面身份

- [ ] 笔试/听力、级别、期次、A/B 圈标、考试时间一致；按用户提供的卷别设置，不用题库目录名推断。封面页数等动态字段反映新结果。
- [ ] 选题、题组顺序、正式题与示范题、总题数、题号连续性符合蓝图；每道四选一保留四个选项，图中已含选项时没有重复再画一份。
- [ ] 重编号后的完形框号、配对后缀、题干指代、表格编号一致；年份、金额等普通数字没有被误替换。
- [ ] 正文、标题、引文出处、注释、选项、图表条件无漏字、重复或串题。错误选项可能故意拼错，不能擅自“纠正答案”。抽取 PDF 文字仅作辅助，ruby 和竖排的抽取顺序可能不同。
- [ ] 字体完整嵌入且符合配置；无方框、替代字符、缺字、意外粗体或混字族。看实际 PDF 与字体报告，测量时请求过的字体不代表最终用到。

### 页码、对页与分页

- [ ] 区分 PDF 物理页与印刷正文页。默认两页封面不计入正文页码；默认有封面时物理页＝正文页＋2，关闭封面或改变装订结构后重新核对，不能固定加减 2。
- [ ] 印刷正文页码、页眉、侧栏、左右版心与装订边连续一致，无重号/漏号。左页是偶数、右页是奇数；用“双页显示且封面单独显示”或实际打印顺序确认，不能靠手机上下滚动判断左右。
- [ ] 对每篇完形/阅读计算“材料＋出处/释义＋全部对应题目”的实际页数，首篇包含大题标题，A/B 对比文本视为一个材料单元。超过一页时左起；文章一页而题目在下一页也属于多页单元。
- [ ] 查看 `material-spreads.json` 并对照实际 PDF。配置 `metadata.assets.reading_interleaf` 是自动花纹隔页的前提；缺该素材时不能宣称自动保证了左起。
- [ ] 多页单元拟从空白右页开始时，应先画花纹填充页，再从左页开始。右页已有前题内容时保留已有内容并换左页，不覆盖前题。前题用了三页后，对下一单元重新判断。
- [ ] 花纹隔页有正确页眉/页码/侧栏，计入正文总页数；只有确需对齐时插入。单页单元可以右起；不要每道题都加空白页，也不要把意外白页误认为花纹隔页。
- [ ] `questions_new_page: true` 对单页材料保留题文分离；正文或释义已经跨页时，题目应在材料末页的剩余空间接排，放不下才继续下一页。某题确需第三页不是错误，强行留白再开第三页才需修复。
- [ ] 信息检索 `layout: facing_pages` 按左题右图核对，不套普通材料的题目接排逻辑；检查整组对页和下一题册起点。
- [ ] 大题标题与首项相邻，不孤悬页底；自然段的两三行短段整体保留，长段跨页首尾至少两行。题干和选项分布合理，没有只剩题号/单字的孤行或无原因的大段空白。

### 字格、行距与换行

- [ ] 普通阅读正文保持 11.3bp、约 24.06bp 行距，完形正文保持标准 19.8bp 行距；普通阅读释义为 24.06bp、完形释义为 19.89bp，完形框外引导语不继承框内行距。这些是当前默认规则，不要把通知、出处或图表专用样式强改成正文行距。用户明确 DIY 改样式时记录新基准。
- [ ] 长文顺延，不能为了“页数跟旧版一样”压行距/字高/字宽。检查同一文章前后、框内外、续页的基线节奏，不仅比较首行位置。
- [ ] 真实段落、对话、收件人、称呼、落款、电话/邮箱/网址分行正确；没有 OCR 自动行末造成的大量硬换行，也没有原本独立的字段挤成一段。
- [ ] 短行/显式换行不被强制拉伸，日文标签不逐字散开，拉丁地址不出现人为插空格；URL、邮箱、数字范围在合理边界断行，不切碎协议头、数值或短标记。
- [ ] 行首行末标点、括号成对，`（注N）`、`（中略）` 等短标记保持整体。日文范围号按正文含义用 `～`，不要以外形相近字符自动全局替换。
- [ ] 长选项、排序题的词块、星号、填空线、圈号/配对后缀可辨认；列宽与题干/选项对齐，换行后的缩进稳定，字符没有掉入相邻列。

### 振假名、正文小注、释义与下划线

三类文字不能混用：

| 类别 | 源码表达/位置 | 检查重点 |
| --- | --- | --- |
| 振假名 | `｜漢字《かな》`；横排上方、竖排右侧 | 与被注词对应，长读音不碰邻字/邻行；分字读音用 `《かん|じ》` 等明确分隔，不能凭字数猜拆分 |
| 正文小注号 | `{{注1|被注词}}`；横排下方、竖排左侧 | 从正文行移到被注词旁；不把整条释义塞进正文，也不把小注号从被注词移到页末 |
| 释义定义 | 正文之后的 `style: small` 段落；在正文框外 | 编号与正文一致，定义读音同样用 ruby；解释性括号照原义保留 |

- [ ] 释义标签按例题排成 `（注１）`，数字占全角字格，无“注1”挤靠；仅规范定义标签，正文年份/金额及小注尺寸保持自身规则。
- [ ] 注音、小注、下划线与相邻基线有足够间隙；需要避让时采用一致的测量/留白规则，不能随机把小注塞回正文或只移动某一题。被注词跨行/跨列时锚定其首部分，不为小注强制整个长词不可拆，也不能在每列重复注号。
- [ ] 下划线范围与题文一致，跨行正确分段，不漏线、不划到小注/读音、不与下一行或框线重叠；①等指示标记与对应片段关系清楚。
- [ ] 定义可在下页继续，但编号不能与定义主体脱离；单条定义优先整条保留，单条超过整页才按行跨页。不要为保留整组定义而把文章最后两行挤到下页、留下大空洞。
- [ ] 完形出处在框外；R8/R11 的出处按既有样例可在框内。材料自身的“注意事项”不是释义定义，不能凡是小字就全搬到框外。

### 框线、竖排、图表与听力

- [ ] 长完形框能自然跨页，续框内边距足够，ruby 不贴上边线；框底不切字、不穿过注释。确需移除边框时先改变组件语义/样式，不用擦白块覆盖最终 PDF。
- [ ] 按各组件的允许区域核对正文、注音、小注、图像和框线，左右页镜像正确；无意外裁切、歪斜、溢出、重叠或被蒙版遮住的内容。区分合法的标点/小注悬挂、框外扩、页眉侧栏和封面出血；包围盒相交只是候选，须查看实际墨迹再判碰撞。
- [ ] 竖排列顺序、标点方向、数字、出处、ruby/小注侧向与原稿证据一致，框宽/列数容纳文本。不能假设“第一道阅读必有一篇竖排”然后任意挑一篇；无证据时按约定横排并列未决。
- [ ] 信息表保留标题层级、日期、金额、条件、注脚、单位、预约符号和联系方式；表格边线/行高/列宽/对齐稳定，长条件完整，标题不孤立，字形不越过单元格。
- [ ] `rule_style: reference` 的字号/留白选择见组件报告；它有专用的有限适配规则，不能借此压缩普通阅读正文。仍放不下时结构化重排/更合理分页或报告限制，禁止裁字删条件。
- [ ] 原始题图清晰、比例正确、没有误旋转/错误裁切；已有文字版可结构化为表格，但不能凭空还原缺失图像。
- [ ] 听力示范与正式题编号规则正确；题图、表格、上下选项和振假名互不碰撞。大图合理独占页；`options_embedded_in_stimulus` 仅在图里确实已有选项时使用，仍保留语义选项数据。

## 如何做视觉检查

先看整页与双页，再放大 ruby、下划线、表格和页底；缩略图/联系表只能导航，不能据此宣布细节合格。建议至少按 2 倍分辨率渲染。若无 Poppler，可使用已安装的 PyMuPDF，下面只渲染指定物理页，避免长卷一次产生大量 PNG：

```sh
python3 - <<'PY'
from pathlib import Path
import fitz
pdf = Path('output/ai-review/N1-paper-a-written.pdf')
out = Path('output/ai-review/qa-pages')
out.mkdir(parents=True, exist_ok=True)
physical_pages = [3, 4]  # 例子：换成实际需要查看的页码；以 1 开始
with fitz.open(pdf) as doc:
    for number in physical_pages:
        if not 1 <= number <= len(doc):
            raise ValueError(f'Page out of range: {number}')
        doc[number - 1].get_pixmap(matrix=fitz.Matrix(2, 2), alpha=False).save(
            out / f'p{number:03d}.png')
PY
```

打开生成 PNG 实际查看。新卷还需完成其余所有页；PDF 页数很大时按范围分批。局部修改可用下列辅助诊断定位变化，再人工检查：

```sh
python3 tests/compare_rule_layout.py examples/N1-paper-a-written.pdf \
  output/ai-review/N1-paper-a-written.pdf --output tmp/ai-layout-diff.json
python3 tests/check_rule_a_rows.py --fonts private/fonts.yaml --output tmp/ai-a-rows.json
```

`compare_rule_layout.py` 不是“退出 0 即外观合格”：同页数仍可能存在差异，报告指标也不是相似度百分比。默认汇总跳过前两页，并裁去页缘/页脚的比较区域，不能据此称整页通过；页面增删后应按材料/题号对应，不能逐页错位比较。`check_rule_a_rows.py` 仅诊断 A 的既有断行，不代替其他卷或像素/内容检查。

## 已发生问题 → 修复路径

文件名均位于 `engine/`。先判断是输入问题还是通用规则问题，下面是排查入口，不是要求每次改所有模块。

| 症状 | 排查与正确修复 | 回归关注 |
| --- | --- | --- |
| 注号挤进正文、释义读音变成括号 | 把输入的小注改为 `{{注N|词}}`、读音改为 ruby；核 `reading_rules.py` / `inline.py` / `rule_typography.py` | 下方小注、上方ruby、下划线同时存在及跨行 |
| 释义在框里，或“注1”缺少字格 | 将定义作为后续 `style: small` 块；标签在统一测量/绘制文本中正规化 | 横竖排、单/多位编号、年份数字不变 |
| 完形很挤、长阅读行距变小 | 移除过小局部行距覆盖；让 `reading_rules.py` 正常断行/跨页，续框留顶边距 | 长文、续框ruby、释义多页；不可用缩字号恢复旧页数 |
| 文章第二页很空，题目却第三页起 | 检查 `questions_new_page` 与实际材料跨页状态，采用现有续页接题规则 | 单页材料仍分题页，多页末页有/无足够空间 |
| 前题用了三页，后题文在右、题在背面 | 核 `reading_interleaf`；`spread_alignment.py` 试排完整单元并逐篇对齐 | 一页文加一页题、三页前题、A/B、已有内容的右页 |
| 花纹页过多、编号跳动或重复绘字 | 检查试排状态是否污染正式布局，不手动补固定页数 | 单页不插页，preview 后游标/题号/语义记录恢复 |
| 邮件落款黏成一段、标签被拉开、网址断碎 | 修复真实段落边界及 contact 等语义角色；核 `reading_rules.py` 的显式换行与字距规则 | 短行、ASCII/日文混排、长URL、悬挂缩进 |
| 框末空洞、孤行、注音碰框顶 | 核末尾保留高度、自然段保留和续框 padding，不把整组释义作为不可拆大块 | 两三行短段、长段至少两行、长定义超过整页 |
| 表格下方选项的ruby碰边线 | 核 `component_layout.py` / `material_primitives.py` / `rule_typography.py` 的表格真实占高和下一行上伸 | 不同列/行数、有无注音、图前/图后选项 |
| 信息题 plain 松散或一页溢出 | 使用 `reference` 语义层级与 `reference_document.py` 共用plan，调整列宽/留白 | 长标题、更多表行、报告最终字号；超限明确失败 |
| 换页后框或文字横向偏移 | 换页前记录相对旧版心的偏移，换页后加新页版心 | 奇偶页、嵌套框、连续多次换页 |
| 字体缺字或封面年份过粗 | 核字体路由和完整字体内部名/字重；年份按 FONTS 的 regular＋固定加粗规则 | 新字、封面年份/圈标、禁止随意跨字族fallback |
| 精简浮点数后换行/字体外形改变 | 仅在scene序列化边界保持既有渲染精度；不粗舍入测量值/校准值 | 同源TeX参数一致、像素回归；保留12.00001bp等边界 |
| 更新后打开的还是旧 PDF | 核本次退出状态、实际输出目录、compiled字段及文件摘要；重新实际编译 | 顶层旧PDF、失败后旧报告、误开examples或其它交付目录 |

测试入口和扩展注意事项见 [development.md](development.md)。修复后将检查结果及残留疑点写进 [验收报告](../assets/qa-report-template.md)；未取得原文证据的内容问题不能因版式变好而销项。
