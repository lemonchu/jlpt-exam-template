# 生成规则与使用边界

默认入口根据当前 YAML、字体和蓝图计算断行、字距、组件尺寸及分页；不加模式参数与显式 `--rules` 等价。可变正文不读取原稿逐字位置，也不按题目 ID、正文字符串或内容指纹选择专用坐标。接近样板外观是目标，不承诺逐像素复现。

安装与首次构建见 [README](../README.md)，字段与示例见[内容和蓝图格式](SCHEMA.md)。规则版即使处理 A/B，也可能需要完整同名字体补字，不能假定内置子集覆盖所有正文角色；见[字体说明](FONTS.md)。

## 构建与输出

入口及默认目录见 [README](../README.md#排版与输出)。

`--output-dir` 可覆盖输出根目录；请与基准目录分开。构建不会自动覆盖 `examples/`。专用蓝图见 [2014 构建说明](../content/paper-2014-12/README.md)。

## 固定模板与可变正文

默认规则版只把封面和排序示范视为固定模板：

- `cover-template.json`：四张封面的设计、元数据槽位和文字适配区域。
- `ordering-template.json`：排序说明与示范的局部文字槽位、线条和方框。

两份数据均在 `profiles/n1-original/`，不依赖旧 A 正文绑定或整页切片。显示文字仍来自当前 YAML；增删正式题目、更改题目 ID 不影响排序模板。修改示范文字或相关样式后，不兼容的部分退回规则生成，不会调用旧正文组件。

其他内容经过“解析文字单元 → 断行与字距 → 测量组件 → 当前游标定位与分页 → 共用 scene 渲染”。图片和手写材料仍须提供素材，不能由文字转录恢复。

## 作者提供语义，不提供逐行坐标

注音、小注、强调及真实标点应写入内容，例如：

```yaml
text: '｜商品《しょう|ひん》を{{注1|__確認__}}してください。'
```

分隔注音明确每个正文字符的读音；不分隔则表示整词 ruby，引擎不会暗设词典特例。显式换行用于作者要求的段落或断行，不要照抄 PDF 的自动行末。完整语法见[行内文字](SCHEMA.md#行内文字)。

`rule_style` 为材料指定可复用的编辑角色，常用入口包括：

| 场景 | 角色入口 |
| --- | --- |
| 对话、引用、承接段落 | `dialogue`、`quotation`、`continuation` |
| 通知材料及联系方式 | `notice`、`contact`、`contact_detail` |
| 图注与紧邻图片组成整体 | `figure_caption` |
| 结构化参考说明框 | `guide` |
| 框内品牌、标题、导语 | `guide_brand`、`guide_title`、`guide_intro` |
| 框内分节、小节、正文 | `guide_section`、`guide_subsection`、`guide_paragraph` |
| 框内表格说明、表题、表格、注意事项 | `guide_table_intro`、`guide_caption`、`guide_table`、`guide_caution` |

这些角色不能替代内容本身，也不是任意宣传页的自动设计器。通知和 guide 仅用于阅读材料的顶层框；图注组合也不支持嵌套进框。竖排引用框只接受竖排正文与文字出处。未知角色、错误块类型或不支持的嵌套会在排版前报错；详见[材料块](SCHEMA.md#材料块)。

## 材料、注释与题页

注释定义行的编号按两套例题统一排为 `（注１）`：输入的半角数字、半角括号或编号空格只在排版时正规化，单个数字保留全角字格，避免“注”和数字挤靠。原始YAML、定义中的年份等数字以及正文行内小注保持原样；测量、换行和绘制使用相同的正规化文本。

释义定义使用 `style: small`，作为正文框的后续块，不能放在框内；材料本身的注意事项不是释义定义。完形文章出处也排在框外，R8/R11出处按例题保留在文章框内。正文中的小注号用 `{{注N|被注词}}` 附在词下，竖排则在词左侧，不应当成定义搬走。释义的读音用 `｜漢字《かな》` 振假名，解释性括注保留原样。`（注N）`、`（中略）`等短标记整体断行；未编号定义统一为 `（注）`。

正文末尾只为相邻出处及框底留白预留空间，释义可以完整续排到下一页，不为整组释义强制带走正文末两行。尾部测量包含正文完整行距，续框另保留顶部内边距，避免注音碰线。自然段的两行、三行短段整体保留，较长段落页首和页尾至少保留两行；显式换行遵照输入，不套用自然段保留。

超过可保留范围的完形注释仍按单条定义流动，每条用相同的断行计划测量和绘制，以最后一行的实际文字占位检查页底。当前页放不下完整一条时移到下一页；单条本身长于整页时，才允许按行跨页。

完形和普通阅读题的 `questions_new_page: true` 保留单页文章的“材料一页、题目下一页”。如果该篇正文或注释已经跨页，题目从材料结束的位置继续排版，不再仅因这个设置强开第三页；剩余空间不足时，仍按选择题自身的完整保留规则换页。`false` 始终允许接排。信息检索的 `facing_pages` 左右对页布局单独处理，不受此续页规则影响。

普通阅读正文采用 11.3bp 字号、24.05996bp（约24.06bp）行距，释义行距24.06bp；完形框内正文的标准行距为19.8bp，释义19.89bp。长文按正常行距自然跨页，不为维持既有页数压缩行距；通知标题、出处、信息表格等专用样式保持各自的测量规则。

提供 `metadata.assets.reading_interleaf` 的规则版试卷，会在每篇完形或阅读材料开始前，用相同的渲染器试排整篇材料、注释与全部对应题目；首篇还计入大题标题。单元超过一页且拟从奇数右页开始时，先补原花纹隔页，使材料从偶数左页开始。A/B 比较阅读是一个完整单元；前一单元占三页时，下一单元重新判断。单页材料可以右起，不额外插页；多页单元拟与前文共用右页时，保留已有内容，直接换到左页。多页材料仍按正常行距自然流动，不压缩成两页。信息检索继续使用专门的左题右图布局。

隔页计入正文页码，保留页眉、页码和侧栏；封面两页不计入正文页码。构建输出 `material-spreads.json` 记录每个材料单元的正文起止页和新增隔页，便于核对双面打印的左右关系。试排与正式排版的题号、文字记录和绘图状态隔离。

## 同页连续题组

`new_page: false` 允许同科目题组接在当前游标后面，不是禁止题目自动换页。`true` 仍为默认值，标准蓝图无需修改。

同页承接添加非负的 `group_gap`，默认取当前行距，并至少容纳标题注音的上伸部分；新页不重复加间距。`start_on` 针对当前页判断。跨科目、左右对页和明确分页约束优先，听力正式题仍使用独立面板分页。

引擎先尝试保留“标题＋完整首题或首材料”。当前页不足则一起移到新页；连新页也容不下时，才对首项放宽可拆内容的整块保留。首项之后恢复通常规则，固定排序示范不可拆。

标题与首项的硬性最小单元仍超过一页，或同页设置使用负 `body_start_adjust`，都会报错。配置示例见[组卷蓝图](SCHEMA.md#组卷蓝图)。

## 扩展规则的约定

先说明某类内容需要什么语义，再定义测量计划与绘制；不能先完整计算旧计划，再丢掉重做。自动选项列数、断行和最终绘制必须使用同一套文字单元宽度。

校准字号、字距和光学偏移集中在具名样式或函数附近。字号不等于字距，不要随意取整；这些是样板归纳出的统一参数，并不声称恢复了官方软件的全部内部算法。

共享计算尽量不修改页面状态。跨页组件先保存 `x - 当前版心左边`，换页后再加上新页版心；不要在换页后才从旧坐标计算偏移。模块分工与回归流程见[维护说明](ARCHITECTURE.md)，可调字段见[蓝图格式](SCHEMA.md#组卷蓝图)。

场景数值只在写出 `scene.json` 时用渲染器既有的12位有效数字格式规范化，例如 `805.8000000000001` 写成 `805.8`；断行、测量、分页和字体适配仍使用原始计算精度。规范化前后的数值必须产生完全相同的 TeX 参数，负零保留，大指数不会展开成更长的整数。字符串（含题文、URL和PDF向量指令）不参与数值改写。不要把接近整数的值一律取整：`0.999995`、字体使用的 `12.00001bp`、校准字距、Bezier比例与比较容差可能有实际含义，应保留。固定模板本身已有的坐标精度与字体轮廓测量值也保持不变。

## 检查外观与扩展性

区分三种验证：改动前后的回归、与官方稿的外观对照、任意新内容的扩展测试。回归通过不能替代官方稿对照。

官方稿是目标外观依据，可从 [JLPT 官方样题入口](https://www.jlpt.jp/samples/sampleindex.html) 查看。`examples/` 保存经过验证的默认规则版 PDF，供展示和回归对照，不随每次构建自动更新；与官方稿存在差异时，应记录差异，而不是复制快照中的错误。

逐页墨迹与字形位移诊断：

```sh
python3 tests/compare_rule_layout.py examples/N1-paper-a-written.pdf \
  output/rules/N1-paper-a-written.pdf --output tmp/rules-comparison.json
```

也可用官方合并稿替换第一个参数。报告默认不把前两页计入总分；`--exclude-page` 可明确排除整页图像。变化像素除以原稿墨迹不是相似度，可能超过 100%；字形匹配也不能证明内容无遗漏。页数或页面尺寸不同须单独检查。

不调用 XeLaTeX 的真实字体断行诊断：

```sh
python3 tests/check_rule_a_rows.py --fonts 本地字体配置.yaml \
  --output tmp/rules-a-rows.json
```

该工具使用 `tests/fixtures/a-choice-rows.json` 中的原稿断行长度，检查 A 的60个题干与260个选项。基准只保存各行字数，检查文字来自当前 YAML；它不参与排版。缺字或字段长度与基准不符会报错。光学空白和冒号形式会规范化，因此它不代替像素检查。

新增规则还需测试长注音、显式换行、窄版心、长图注、表格增行、竖排列数及左右页切换；续排须覆盖标题连首项换页和可拆/不可拆边界。不可容纳的内容应报错，不能静默裁掉。

无限任意内容、固定页数和逐像素复现不能同时保证。局部字距、字形轮廓、手工光学调整及整页素材比例仍可能与原稿不同；应保留可解释的共享规则，把未解释的差异记入报告。

### 通知与信息表材料（reference）

顶层阅读材料框可用 `rule_style: reference`。子块按已有文字标为
`reference_brand`、`reference_title`、`reference_subtitle`、`reference_section`、
`reference_subsection`、`reference_body`、`reference_note`、`reference_caption` 或
`reference_contact`；普通表格及嵌套框均可保留。它按材料内容生成相对位置，
不按年份、题号或旧PDF坐标绑定。既有 `guide` 和 `notice` 的校准规则不变。

普通材料正文优先10.5bp、表格10bp，标题14.5bp；外框0.6bp、内边距18bp。
长材料先减少段间和表格上下留白，再依次采用10bp或9.5bp正文；最低表格9bp。
最终选用字号、间距比例、测量高度写入 `build-report.json` 的对应component，
不能通过删字或裁切凑一页。超过可用高度会显式失败。材料测量与绘制使用同一plan。
表格的原始列宽比例、对齐和单元格文字均保留；需要改善列宽时在材料中明确配置，
金额和预约符号可居中，长条件仍左对齐。标题、段落和表格调整后必须查看最终整页。

字符修订与版式修订分开记录。半角波号在特定字体中可能呈重音符形，范围号应采用
日文全角 `～`（例如 `A～C`）；标签拆分或明确换行不得删除条件、日期或数字。
