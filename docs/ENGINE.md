# 共用排版引擎

## 构建链

`content/<paper>/` 的语义内容与 `blueprints/` 的布局配置进入 `build.py`，按题组组装为场景；场景统一由 `engine/calibrated_renderer.py` 输出 XeLaTeX。A、B、新建内容目录经过同一个入口，使用同一份字体目录和组件实现。

仓库内置原版子集与现有题目所需的同款补充子集，完整字体由使用者通过 `fonts.yaml` 按需配置。`tools/prepare_fonts.py` 保留从已有项目或第一版原始 PDF 恢复原版子集的可选入口。模板运行时只读取当前 YAML、实测几何、绑定规则、本地字体和明确引用的图片素材。`profiles/n1-original/layout.json` 没有题目文字；`body-bindings.json` 把字形位置绑定到 YAML 字段及字符索引，`glyph-capacities.json` 只保存字形进位宽度数值，用于识别同字数但字形变宽的改动。字体的私有码仅用于字体内部字形寻址，不是作者输入格式。

## 组件决策

1. 若题组结构、字数、字形进位宽度、注音及样式位置适合实测约束，每次从当前 YAML 重新解析字形，保留实测位置。
2. 若容量改变，仅该题组重新组版，继续使用相同字体角色与排版规则。标题、例题页、参考材料页仍可独立保留兼容的实测组件。
3. 未改内容的组件换页时，移动正文到新页的镜像版心，并重新生成页码、页眉、侧栏。配置改变侧栏也会刷新实测页的装饰。
4. 不存在根据 paper-a/paper-b 文件夹选择渲染器的逻辑。`--recompose` 是开发诊断选项，强制重算全部可变组件；通常不必使用。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `engine/component_layout.py` | 选择题、完形、横竖排阅读、听力题组与分页 |
| `engine/material_primitives.py` | 图片、表格、框线和基本流排原语 |
| `engine/reference_components.py` | 实测约束、当前语义绑定、组件移动与局部复用 |
| `engine/component_fonts.py` | 所有组件使用的字体角色、字宽、补字 |
| `engine/font_overrides.py` | 原字形优先、按原字体名称接入完整字体 |
| `engine/page_furniture.py` | 页眉、页码、侧栏 |
| `engine/inline.py` | 注音、下线、小注、编号框和禁则换行 |
| `engine/metadata_bindings.py` | 封面与公共文字的实测绑定 |
| `engine/metadata_components.py` | 封面字段变长、英文变宽、页数变化时的原区域重排 |
| `profiles/n1-original/n1-exact.sty` | XeLaTeX 字形、图片、矢量绘制原语 |

## 默认尺寸

单位为 PDF bp，坐标按组件接口注明的原点使用。纸张595×842。文字卷奇数页左边界78.96、偶数页63.63，版心宽452.41；正文11.3，行距24.05996。G7文章11.3/19.8，注释定义19.89间距。听力正式选项14.2/28.35，标题36；题号两组基线81.4489、449.7589。

这份参数表只给出主要规则。原稿中局部缩排、字间距、纵横缩放和特殊题号字体在实测组件中继续保留，不能只用一个 font size 概括。Ruby超过汉字宽度时压缩注音，不扩宽正文。

`page` 支持 `left_odd`、`left_even`、`body_width`、`margin_top`、`body_bottom`、`font_size`、`line_height`。完整原版封面仍以595×842设计；若要换纸张，应另建封面设计。常规命题建议保持纸张和主要字体尺寸。

## 输出与审计

每个输出目录包含：

- `scene.json`：可重现的绘制命令。
- `resolved.json`：本次从当前内容解析的字形语义及当前图片路径。
- `selected-content.yaml`：筛选、重排和编号后的内容快照。
- `inputs/`：输入 YAML 快照及蓝图。
- `build-report.json`：各题组采用实测还是重新组版、页数与输入摘要。
- `render-report.json`：字形数、实际字体路由及字体策略。
- `main.tex`、`pages/`、`fonts/`、`assets/`：独立可编译 LaTeX。

这些生成文件包含本次试题文字，`fonts/` 中还可能包含本地字体子集；生成目录不纳入公开源文件。它们不是下一次构建的题库。作者修改 `content/` 后重新构建，输出会重新产生。

## 特殊材料边界

外部图片只用于封面背纹、指定的防透页、手写便笺和独立广告/图表。不会把整页试题作为排版背景。PDF素材只取第一页。`alt` 是作者说明，不改变图中的文字。

表格等不可分割单元超过页面时给出错误；左右对照参考材料要求各占一页。复杂材料可作为独立PDF图片，题干选项仍保留文字。原字体缺字只在同一原字体的其他原版子集、内置补充子集和配置的对应完整版中查找，并记入报告；缺少资源或字形时明确报错。现代完整字体与原稿旧 CID 可能存在轮廓差异，不能把新增字形说成已经验证与旧版逐点相同。
