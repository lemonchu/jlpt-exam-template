# v0.1.0：共用 YAML / LaTeX 试卷模板

本版本面向 `dev` 分支，以普通源文件组织，包含 A、B 两套 V/G/R/L YAML 内容，以及同一套 XeLaTeX 排版组件。文字卷和听力题册分别构建；可以修改题库、筛选和重排题组、调整编号与侧栏，并将末题广告或图表作为独立素材引用。

开始使用请阅读根目录 `README.md`。内置原版旧字形子集及现有题目需要的少量同款补充字形，A/B 四册可直接编译。完整字体不随仓库分发；自编题目出现内置字库外的字符时，再通过 `fonts.yaml` 配置对应完整版，详见 `docs/FONTS.md`。

旧 CID 字形与已找到的现代 OpenType 字体存在差异；已有原字形可保留，新字使用对应完整字体，不承诺任意新内容与旧版本逐点相同。默认 A 的历史回归结果也不代表所有机器都能得到相同渲染像素。

源码遵循根目录 `LICENSE` 中的 GNU AGPLv3；原题、文章、广告图和字体不因此被重新许可，见 `THIRD_PARTY_NOTICES.md`。

本次不上传独立 ZIP 或预编译 PDF 附件；源码直接保存在仓库。完整源码以 `dev` 为提交目标，`main` 暂仅保留项目说明。GitHub 自行提供的源码下载入口不属于本项目额外制作的发布附件。
